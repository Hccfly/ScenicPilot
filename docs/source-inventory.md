# 珠海长隆资料范围与清单

核验日期：2026-09-09

## 结果

本阶段建立 50 条页面级来源记录，全部来自长隆官方域名，且 URL 与 `source_id` 均不重复。数据分为四组：

- 园区、交通、FAQ、公告等入口：14 条；
- 五类住宿及其餐饮、权益页面：14 条；
- 海洋王国独立景点页面：10 条；
- 飞船乐园独立景点页面：12 条。

## 知识边界

首期覆盖海洋王国、飞船乐园、横琴湾酒店、企鹅酒店、马戏酒店、飞船酒店、迎海酒店公寓、交通、餐饮、表演、FAQ 和公告。暂不把用户评论、非官方攻略和票务平台内容作为事实来源。

当前 curated 数据是“已核验的来源目录 + 页面摘要”，不是网页镜像。采集与切块阶段 再实现正文抓取、正文清洗、内容哈希、切块和增量索引。

## 时效分层

- `refresh_days=1`：公告、演出安排等高频变化页面。
- `refresh_days=7`：交通、餐饮、酒店权益和服务规则。
- `refresh_days=30`：园区与景点介绍。

凡标记 `volatile=true` 的记录，检索结果只能作为核验入口；生产回答必须结合到访日期重新查询。景点介绍页虽然主体描述较稳定，但设施状态、适龄范围与安全守则可能调整，因此同样按易变来源处理。

## 验收门禁

`scripts/validate_sources.py` 离线检查以下条件：

1. 资料数量在 30～50 条之间；
2. `source_id`、URL 唯一且字段完整；
3. 来源限定为 HTTPS 的长隆官方域名；
4. 所有记录均为 `zhuhai-chimelong`，并明确不是 demo 数据；
5. JSONL 与 CSV 清单一致；
6. 易变分类必须启用实时核验策略。

`--check-network` 可额外并发检查 HTTP 可达性，但不纳入离线测试，避免网络波动造成错误回归。
