# 数据与时效策略

## 来源优先级

1. 景区官方网页、官方公告、官方小程序可验证页面。
2. 政府交通、气象、文旅等公共数据。
3. 经人工复核的平台资料。
4. 游客经验只用于偏好提示，不用于票价、时间等确定性事实。

发生冲突时依次比较 `authority_level`、`verified_at` 和信息适用范围；仍无法判断时同时呈现冲突并建议用户核验官方渠道。

## 易变字段

票价、开放时间、演出场次、交通班次、酒店权益、天气和库存必须标记 `volatile=true`。静态知识库只提供背景和核验入口，最终回答在生产环境中应调用实时工具。

## 引用与拒答

回答中的事实必须能映射到检索 chunk。检索分数低于阈值、来源失效或资料冲突无法消解时，系统应拒绝给出确定结论，并说明缺少何种证据。

引用编号按唯一来源分配，同一来源的多个证据块复用同一个编号。回答器除检索分数外还
检查主题词覆盖、来源状态和权威等级；实时排队与现场库存没有实时工具证据时直接拒答。
结构化冲突依次按 `authority_level`、`verified_at` 和适用范围裁决，同级仍冲突时只披露
不同记录，不输出确定值。
